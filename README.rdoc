= DriDataModels

This is the Ruby Gem for the Digital
Repository of Ireland's Hydra-based data models.

DRI data models gem (which is stable to develop against) has the following features:

Core Features:

* Collection/Sub-collection Objects
* Metadata Digital Objects
* DRI Generic Files (for digital assets)

Supported metadata formats/standards

* Simple/Qualified Dublin Core (DC/QDC)
* Encoding Archival Initiative (EAD)
* Metadata Object Description Schema (MODS)
* Machine-Readable Cataloging (MARC-XML)

== Requirements

* Hydra-head 9.0 or greater.

== Usage

To use this data model in your hydra application please add the following
to your Gemfile

  gem 'dri_data_models', git: 'ssh://git@tracker.dri.ie:2200/drirepo/dri_data_models.git'

Note: the above repository url will be changing in the near future.

== Running the tests

To run the tests please ensure that you have the 'hydra-jetty' package
or your own instance of Fedora-Commons or SOLR running.

To run the tests, the following command is required

  $ rake rspec
