= DriDataModels

This is the prototype Ruby Gem for the Digital
Repository of Ireland's Hydra data models.

DRI data model (which is stable to develop against) has the following features:

Core Features:

* Collections Object
* Digital Object
  - Audio Data type
  - PDF Data type

Supported metadata formats/standards

* Qualified Dublin Core

== Requirements

* Hydra-head 5.0.0 or greater.

== Usage

To use this data model in your hydra application please add the following
to your Gemfile

  gem 'dri_data_models', :git => 'git@dev.forasfeasa.ie:dri_data_models.git'

Note: the above repository url will be changing in the near future.

== Running the tests

To run the tests please ensure that you have the 'hydra-jetty' package
or your own instance of Fedora-Commons or SOLR running.

To run the tests, the following command is required

  $ rake rspec
